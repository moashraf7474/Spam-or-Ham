# 📩 Spam Classifier (Machine Learning Basics)

This project is a simple **text classification system** that detects whether a message is **Spam or Ham** using classical Machine Learning techniques.

The main goal is not complexity, but to reinforce fundamental ML concepts through a real-world NLP task.

---

## 🚀 Features

- Text preprocessing using **TF-IDF Vectorization**
- Multiple ML models:
  - Naive Bayes
  - Logistic Regression
  - Support Vector Machine (SVM)
- Model evaluation using:
  - Accuracy
  - Precision
  - Recall
  - F1-score
- Simple interface for real-time prediction (optional GUI)

---

## 🧠 Key Concepts Practiced

- Overfitting vs Underfitting
- Precision vs Recall trade-off
- Model evaluation metrics
- Text preprocessing (NLP basics)
- Feature extraction using TF-IDF

---

## 📊 Dataset

SMS Spam Collection Dataset (labeled text messages as spam or ham)

---

## ⚙️ Tech Stack

- Python
- Pandas
- Scikit-learn
- Numpy
- NLTK
- (Optional) Tkinter / Streamlit / Gradio for UI

---

## 📈 Workflow

1. Load and clean dataset  
2. Preprocess text data  
3. Convert text into numerical features (TF-IDF)  
4. Train ML models  
5. Evaluate performance  
6. Make predictions on new messages
